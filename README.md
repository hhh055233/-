# SHALAT

אפליקציית Android בעברית לזיהוי מזגנים ולמציאת פרופיל שלט לפי מספר דגם מדויק.

## מה קיים בקוד

- ממשק Expo React Native כהה בעברית.
- צילום מזגן והעלאת התמונה לשרת הזיהוי.
- בקשה לצילום מדבקת הדגם כאשר לא ניתן לקרוא מספר דגם מדויק.
- התאמה רק לפרופיל שמסומן במפורש כמאומת, לפי מותג ומספר דגם מדויקים.
- מסך מרכז עדכונים המציג סטטוס שרת, גרסת מאגר, מספר פרופילים מאומתים ומחקר חיבורי Wi-Fi.
- חיבור MY TADIRAN לא רשמי באמצעות אימות SMS, שמירת refresh token ב-Android SecureStore, הצגת מזגנים ופקודות ענן לדגמים ברשימת allowlist קהילתית.
- הגבלת קצב סריקות וניסיונות אימות, בדיקות שרת אוטומטיות והפרדה בין מאגר פרטי למידע ציבורי.

## מגבלות חשובות — לא להציג כהשלמה

- אין כרגע פרופילי IR מאומתים במאגר (remotes ריק). רשימת הפרוטוקולים היא מלאי טכני בלבד, לא קודי שלט למזגנים.
- התאמת פרופיל שלט אינה משדרת פקודות. נדרש משדר IR חיצוני תואם או חיבור Wi-Fi ספציפי שעובד עם הדגם.
- חיבור Tadiran הוא אינטגרציה לא רשמית לשירות ענן. רשימת הדגמים נשענת על פרויקט קהילתי; SHALAT לא אומתה פיזית מול מזגן, ותשובת ענן אינה הוכחה שהמזגן ביצע את הפקודה.
- Tornado: קיימת אינטגרציה קהילתית ל-AUX Cloud, אך היא עדיין אינה מחוברת ל-SHALAT. לא להכניס פרטי חשבון עד שהחיבור ייבדק ויוגן.
- Spectra: אין כרגע חיבור ענן ייעודי או פרופיל IR מאומת. התאימות תלויה במספר הדגם המדויק.
- לכן לא ניתן להבטיח שליטה מלאה לפני בדיקות מול מזגנים אמיתיים וחומרת שידור מתאימה.

## הרצה מקומית

```bash
npm install
npx expo start
```

בדיקת TypeScript:

```bash
npm run typecheck
```

בדיקות שרת:

```bash
npm run test:server
```

## שרת Render

- כתובת: https://shalat-api.onrender.com
- Build: `cd server && npm install`
- Start: `cd server && npm start`
- משתנה סביבה נדרש לזיהוי תמונות: `GEMINI_API_KEY`
- מאגר שלטים פרטי: `SHALAT_CATALOG_JSON`
- אין לשמור מפתחות API, סיסמאות או קודי SMS בקוד המקור או בצ'אט.

## APK

`eas.json` כולל פרופיל `preview` ל-APK. לפני בנייה דרך EAS יש לקשר את פרויקט Expo האמיתי באמצעות `extra.eas.projectId` שנוצר בחשבון Expo. אין להמציא מזהה פרויקט.
