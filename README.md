# SHALAT

אפליקציית Android לשליטה במזגנים באמצעות מאגר שלטים דיגיטליים.

## מה כלול כרגע
- שלד Expo React Native בעברית ובעיצוב כהה.
- בחירת תמונת מזגן מהמכשיר.
- מסך מאגר ראשוני לחברות Samsung, LG, Electra, Tadiran ו-Tornado.
- תצוגת שלט אינטראקטיבית להדגמה ומרכז עדכונים.

## חשוב לדעת
זוהי גרסת בסיס לממשק בלבד. בחירת תמונה עדיין אינה מחוברת לשירות זיהוי AI, ותבניות השלט הן דוגמאות שאינן מאומתות. הכפתורים אינם משדרים IR או פקודות Wi-Fi. יש להוסיף בהמשך שרת זיהוי, מאגר קודי שלטים שנבדקו, ומתאמי Wi-Fi/IR תואמים.

## הרצה

```bash
npm install
npx expo start
```
